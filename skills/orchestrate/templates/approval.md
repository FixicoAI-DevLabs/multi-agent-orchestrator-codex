# Human approval request

Present the completed plan and assignment table before asking. Replace all
bracketed fields with concrete values; this template is not authorization.

> Approve plan [revision/reference] for run [run ID] at [workspace/baseline].
> Create [named separate chats] with [models/efforts and environments], limited
> to [assignment actions and owned paths]. Permit the original lead [chat/host]
> to message those chats and permit them to send progress, blockers, and results
> back to that lead. Permit [corrections/continuations] within [limits]. Return
> to me for [material scope changes and excluded actions].

Point `human_source_ref` to the actual human message after it exists. Fill the
approval record's plan/origin/lead/limits/contract snapshots from that approved
scope; set only the permissions actually granted. Have the worker verify the
source. Neither this template nor a coordinator-authored JSON object supplies
approval. Reuse valid unchanged approval instead of asking at every step.
